# ADR-0003: 計測信号＝手セグメンテーションマスク＋付け根/PIP最大円周

- ステータス: Accepted
- 日付: 2026-05-30
- 関連: ADR-0002, ADR-0004

## コンテキスト

指幅の計測は当初、指軸に垂直な走査線上で Canny エッジ / 輝度勾配の極大を探す方式
だった。これは背景の模様・肌の照明ムラ・影に弱く、エッジを取り違えて幅が乱れる。

また、号数を決める物理制約は「指輪が指の最も太い断面を通過できること」であり、それは
多くの場合 **PIP 関節**だが、人によっては**付け根（基節）**の方が太い。当初実装は
MCP→PIP 間の中ほど（比率 0.25〜0.45）のみを測っており、最も太い断面を取り逃す。

## 決定

### 計測信号をセグメンテーションマスクに置換（背景/照明非依存）

`HandSegmenter` を新設し、手シルエットの二値マスクを得る。実装は Otsu 二値化 →
ランドマークの多数決で前景の極性を決定（手が背景より明/暗どちらでも可）→ モルフォロジで
整形 → ランドマークを最も多く含む連結成分のみ採用（背景ノイズ除去）。

`FingerMeasurer` はエッジ走査を撤去し、指軸に垂直な走査線上で**中心点を含むマスク
True の連続区間長**を幅とする。マスクの境界＝シルエット境界なので、背景や照明の絶対値に
依存しない。

### 付け根と PIP 関節の両方を測り、最大円周を採用

付け根領域（水かきを避けた MCP 寄り）と PIP 関節領域それぞれで複数比率の幅を測り、
MADベースのロバスト中央値を取る。幅は周囲長に対し単調なので、**両者の最大幅＝最大円周**を
号数決定に採用する。`FingerMeasurement` に `base_width_mm` / `pip_width_mm` を保持して
透明性を確保する。

## 根拠

- セグメンテーションは「指 vs それ以外」という意味的境界を直接与えるため、エッジ走査の
  ような局所的な誤検出が起きにくい。
- 「指輪が通過できる最小内径」は最大断面で決まる。付け根と PIP のどちらが太いかは個人差が
  あるため、両方測って大きい方を採るのが号数の物理に忠実。

## 影響

- 計測パイプラインは「セグメント → 各指で付け根/PIP幅 → 最大採用 → 周囲長推定」に変更。
- マスク品質が新たな精度要因になる。Otsu は単純背景前提で、複雑背景では学習ベースの
  セグメンテーションへ差し替える余地を残す（`HandSegmenter` をインフラ層に分離済み）。
- 付け根計測は水かき近傍で隣接指と連結しうるため、計測比率は水かきを避けた遠位側に置く。

## 代替案と却下理由

- **Canny/勾配エッジ走査の継続**: 背景・照明依存で号数に効く幅が安定しないため却下
  （本ADRが置換対象）。
- **PIP のみ計測**: 付け根の方が太い指を取り逃し、号数を過小評価するため却下。
- **学習ベースの手セグメンテーションを即導入**: モデル配布・推論コストが増える。単純背景
  での撮影を案内すれば Otsu ベースで足り、まず軽量実装で価値を出す（XP）。将来の差し替えは
  インフラ層の差し替えで対応。
