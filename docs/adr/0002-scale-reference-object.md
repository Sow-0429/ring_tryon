# ADR-0002: スケール基準物（ID-1カード主軸＋コインフォールバック）

- ステータス: Accepted
- 日付: 2026-05-30
- 関連: ADR-0003, ADR-0004

## コンテキスト

px→mm のスケール校正には、画像内に既知寸法の基準物が要る。当初は「中指の実長を
ユーザー入力」する方式（`FingerCalibrationInput`）だが、ユーザーが自分の指を正確に
測れず系統誤差が入る。号数は周囲長 ~1mm 刻みのサブmm精度を要求するため、基準物の
寸法精度がそのまま号数精度の天井になる。

## 決定

スケール基準物を、規格で寸法が固定された物体に置く。

- **主軸: ISO/IEC 7810 ID-1 カード**（クレジット/IC カード = 85.60 × 53.98mm）。
  誰でも持っており寸法が厳密に規格化されている。矩形検出 → `minAreaRect` で長辺/短辺の
  px を取り、長辺由来・短辺由来の px/mm を平均して頑健化する。
- **フォールバック: 100円玉**（直径 22.6mm）。カードが無い場合に使う。
- **指実長入力**は最後の手段として残すが、推奨しない。

さらに、基準物には**検証ロジック**を必須とする（誤検出はスケール全体を狂わせるため）。

- カード: 矩形であること＋アスペクト比が ID-1 規格（≒1.585）に近いことを検証。
  規格から外れる矩形（正方形等）は棄却。
- コイン: 円形度（4πA/P² ≥ 0.80）＋サイズ妥当性（Hough半径と実輪郭面積の充填比）で
  検証。非円形物体は棄却。

## 根拠

- 規格寸法物はユーザー入力誤差を排除でき、系統バイアスを断てる。
- カードは矩形＝2軸の寸法が取れるため、片軸ノイズに対し平均で頑健。コインは円対称で
  向き不問だが 1 次元（直径）情報のみ。よってカードを主軸に。
- 検証なしの検出は「それっぽい矩形/円」を拾ってスケールを大きく外す。号数では致命的な
  ため、検出器に妥当性ゲートを内蔵する。

## 影響

- Python 側に `CardDetector` / `CardCalibrator` / `DetectedCard`（計算用内部表現）を実装。
  API は `use_card` / `use_coin` / `middle_finger_length_mm` のうち**ちょうど1つ**を要求。
- 検証で棄却された場合は実用的なエラー（「カードを手の横に置いてください」）を返す。
- カード/コインの検出精度自体が新たな誤差源になるため、ADR-0004 の較正ループで
  実測号数に対して系統バイアスを吸収する前提。

## 代替案と却下理由

- **指実長入力のみ**: ユーザー測定誤差が大きく、サブmm精度に届かないため主軸から降格。
- **A4 等の大型基準物**: 撮影構図に入りづらく携帯性が悪いため却下。
